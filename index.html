A framework for measuring what matters.

    About this prototype

    I built this interactive framework to explore how complex learning and design decisions can be evaluated across three dimensions: organizational value, learner/user value, and technical feasibility. Rather than producing a single “right” score, the tool is designed to surface tensions, assumptions, and useful next steps.

    It is intentionally a working prototype. I’m using it to externalize my own decision-making process, make the framework testable, and learn where the model needs to evolve once people use it on real problems.

    One use case I’ve been exploring is the shift from AI-detection software toward structured conversations with students about how they used AI, including whether their use adhered to departmental standards for AI use in papers and projects.

    Three lenses. One honest picture.

    A project can succeed on paper and still fail the people using it, or delight users and still be impossible to build. This tool walks through a project or decision using three lenses, then shows where they agree and where they pull against each other.

    ROI Return on Investment

    The business case

    Did we move the right metrics? Completion rates, engagement, error reduction, time on task.

    ROV Return on Value

    The user experience case

    Did it feel better for the person using it? Less friction, less anxiety, content that felt made for them.

    ROT Return on Technology

    The feasibility case

    What was possible within real constraints? Compliance, accessibility, platform limits, legacy architecture.

    The tension is the point. A high score on one lens isn't the goal. The gaps between lenses are where the most useful conversations start.

    It takes about five minutes. Nothing is saved or sent anywhere; everything stays in this browser tab.
